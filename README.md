# Student Management System

A console-based Java application developed to manage student records efficiently using CRUD operations and persistent file storage.

---

## Features

✅ Add Student  
✅ View Student Records  
✅ Search Student by ID  
✅ Update Student Details  
✅ Delete Student  
✅ Duplicate ID Validation  
✅ Exception Handling  
✅ File Handling for Data Persistence  

---
